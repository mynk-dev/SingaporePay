# SingaporePay

Production-grade payment microservice built using Clean Architecture, Domain-Driven Design, and CQRS.

## Architecture

Layered architecture with strict dependency rules:

API → Application → Domain ← Infrastructure

## Tech Stack

* .NET 10
* ASP.NET Core
* EF Core
* MediatR
* SQL Server

## Status

Core payment pipeline implemented.

Demonstrate enterprise-level backend architecture and system design capability.
